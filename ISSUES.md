## Questions for the GMs

Rules questions only a GM or the designers can answer. The planner's current reading is in brackets.

1. **"+5 skill points in either A, B, C..."** (every race, and some classes like Fae Knight: Willow Style): can the 5 points be split, or must they all go into one skill? *(Planner: split allowed.)*
2. **Crafting classes' Level 3** (Alchemist, Armorsmith, Carpenter, Forager): "exchange any skill point for 2 expertise points... in these skills" - does that include the fixed +5 in the crafting skill? *(Planner: allows it.)*
3. **Stat training breakthroughs:** is there a maximum for a stat? *(Planner: no cap.)*
4. **Blocking:** Block sets Guard to 2 x Toughness + armor Block value. Do armor Guard and Guard bonuses from abilities (Stoneskin, stances) also add while Blocking? *(Planner: no, kept separate.)*
5. **Unholy Strength** (+2 Power / +2 Focus): does it also raise max Mana, or only attacks? *(Planner: full stat bonus while on.)*
6. **High Fae:** does Faerie Flash II replace the Fae race's Faerie Flash, or do you have both? *(Planner: both listed.)*
7. **Demon** proficiency choice: which skill is "tied to" each demon clan for the +5 skill-points option?
8. **Mandate keyword:** what happens when you "defy the mandate"?
9. **Curse of Vampirism:** "Wounds only from fire, holy or true damage" - Injuries, or mortal wounds?
10. **Become Lightning (Raijin):** it mentions a Power bonus from Consume Lightning, but Consume Lightning gives a damage bonus (Lightning Boost). Which is it?

## Rulings and readings the planner uses

Answers already given (by the user, 2026-10-24):
- **Mystic Eyes:** anything with the Mystic Eye keyword is a Mystic Eye; each eye takes a slot (2 normally, 3 with Third Eye, 8 with 8 Eyes). The planner counts one per eye class.
- **"Any tier 2 class mastered":** no difference in practice - every tier 3 class needs a tier 2 mastered to enter.
- **Executor:** Acolyte taken + any class mastered; a mastered Acolyte counts.

From the official rulebook:
- Wearing armor or a shield you're not proficient with: 1 less Guard and 1 more Evasion penalty. A weapon you're not proficient with counts as improvised.
- Musket is a common ranged weapon. "Speciality weapons" = the Specialized Weapons list (Pistol, Shotgun, Sniper Rifle, Saboteur Thread Daggers, Lance, Whip, Gauntlets, channeling and gatherer/crafter weapons).
- An ability you'd get twice is a full EXP refund (handled automatically); a near-match is a half refund (shown as a note).
- Artifice (a Reason skill) and Artificing (Artificer crafting) are two different skills.
- Mirane Expedition rules come from the official Mirane guide (Google Doc): +1,000 Clim, free Adventurer's Kit, no restricted options at creation, resting one tier lower, astra resistance = Spirit Core / 500.
- Mirane new-character guide (supplement doc, 2026-10-25): food units 0.5 Clim (40u = 1 day = 20 Clim; a ration is 40 Clim), Arrival IP on arrival (Train +25 EXP, Job 150 Clim or Rest), Armor Plates suggested over Light Armor for light builds, regular clothing is free. Shown as notes in the planner.
- A costs table found 2026-10-25 lists Skill Training 50 and Secondary Stat Training 250; the official site (0.13.2) says 25 and 200, so the planner uses 25 and 200.

How unclear page wording is read (change here and in the data if a GM says otherwise):
- "X" in an ability with a "Variable MP" / "X MP" cost = Mana spent (confirmed on the official site for Glacial Wall and Time Dilation).
- Bonuses that only say "evasion" add to Evasion, not Dodge evasion; "evasion and dodge" changes both.
- Fighter's Journey "+5 HP" = +5 max HP. Angelblooded / Vampire Lord "+1 Presence" is counted once.
- Dragoon: Lancer mastered AND (10 Athletics (Jumping) expertise OR Jiangshi). Thief: Rabbitfolk OR (Rogue mastered AND Decipher Magic).
- "Fae Flash" in Fae Flash Acrobat = the Fae racial ability Faerie Flash. "Iaido style" (Sword Saint) = Iai Style.
- Become Ice / Lightning / Wind: the free use comes back at the start of each of your turns.
- Elemental Convergence's "count as mastered" lasts one encounter, so it doesn't count for class requirements.
- Battlemaster's Arms Mastery proficiency doesn't count for class requirements.
